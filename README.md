# Clay Pigeon - a CLI Client for Bluesky

This project aims to evolve into a fully featured CLI client for Bluesky.

I call it clay-pigeon because on bsky a post is called a "skeet", and if
you've ever gone skeet shooting, clay pigeons are what they call the clay
disks that get flung up in the air which are then shot at.
